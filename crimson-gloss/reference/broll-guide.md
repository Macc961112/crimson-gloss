# Guía de B-roll (qué es, cuándo y cuánto)

Resumen de lo que dicen las guías públicas sobre B-roll y cómo se traduce a los *layouts* de esta skill.

## Tipos de B-roll → layout
| Tipo habitual | Para qué sirve | Layout de la skill |
|---|---|---|
| **Plano de situación** (*establishing*) | Mostrar dónde ocurre la escena (2–4 s) | `scene` (mundo: bosque, mar, ciudad…), `image` |
| **Cutaway** | Detour breve que da contexto a lo que se dice | `phone`, `image`, `clip`, `polaroids` |
| **Plano detalle / insert** | Atrae la atención a un detalle concreto | `callout`, `stat`, `meter` |
| **Ambiente / atmosférico** | Crear sensación o emoción | `rain`, `reaction`, `magic`, mundos con efectos (nieve, burbujas, estrellas) |
| **Captura de pantalla** | Si mencionas un menú, panel o resultado digital, enséñalo | `browser`, `terminal`, `chat`, `notifs`, `progress` |
| **Textos de apoyo** (*callouts*) | Mostrar cada etapa mientras la explicas | `steps`, `checklist`, `timeline`, `compare` |
| **Pantalla dividida** | Mostrar algo sin perder al hablante | `split` |
| **Rótulo (lower third)** | Nombre y cargo | `plan.lower` (modo normal) |
| **Proceso paso a paso / manos** | Enseñar cómo se hace | `steps`, `terminal`, `clip` |
| **Prueba social** | Credibilidad | `rating`, `notifs`, `headline`, `polaroids` |
| **Oferta / precio** | Llamada a la acción | `price`, `countdown` |

## Ritmo (reglas prácticas de las guías)
- Cada B-roll dura **2–4 s**; en un video de 60 s, de **3 a 6** cortes. Más que eso cansa: *B-roll de pared a pared es tan malo como no tener ninguno*.
- Cada B-roll debe **ilustrar lo que se dice en ese momento**, no decorar.
- Deja **espacio libre** para subtítulos y textos: no llenes toda la pantalla.
- Los números concretos (cifras, porcentajes) son el mejor candidato a B-roll visual.
- Las cifras de las guías son reglas de dedo de blogs de herramientas, no estudios.

## Cuentos infantiles y contenido educativo
- Un cuento corto se planifica como **~10 láminas** (*storyboard*); cada lámina = una frase o dos.
- Los **personajes deben ser consistentes** entre láminas (aquí: el mismo emoji para el mismo personaje).
- Las **fábulas** terminan con **moraleja** (layout `moral`).
- Lectura guiada: el texto se **resalta palabra a palabra** mientras se narra (layout `storybook`).
- Educativo preescolar: **contar** del 1 al 5/10 (`counting`), **letras** (`letter`), **formas** (círculo, cuadrado, triángulo, estrella, corazón, óvalo… `shapes`) y **colores**.
- Apertura típica «Había una vez…» (`title`) y cierre «FIN» (`theend`).
